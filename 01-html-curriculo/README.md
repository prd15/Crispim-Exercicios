# Exercício 1 - Currículo em HTML

Trabalho pedido no final do PDF `01 - HTML.pdf`:

> Faça seu currículo em HTML. Tem que ter texto, foto, menu para uma tela de contato,
> textos com recuo, fontes estilizadas, cores, degradê, link que funcione. Na página
> contato deve ter informações também. Faça em tela única, o menu quando clicar em
> contato vá para a parte de contato.

## Como abrir

Abra o `index.html` no navegador (dois cliques já resolve).

## Onde está cada item pedido

| Item | Onde |
|---|---|
| Texto | seções Sobre, Formação, Projetos |
| Foto | `img/foto.jpg`, no cabeçalho |
| Menu | `<nav>` no cabeçalho, com âncoras `#sobre`, `#contato`, etc. |
| Texto com recuo | `text-indent: 35px` na regra `section p` do CSS |
| Fontes estilizadas | Merriweather nos títulos e Open Sans no corpo (Google Fonts) |
| Cores | paleta azul/verde definida no CSS |
| Degradê | `linear-gradient` no `header` e no `footer` |
| Link que funciona | e-mail (`mailto:`), GitHub e LinkedIn na tabela de contato |
| Tela única | tudo no mesmo `index.html`, o menu só rola até a seção |

## Para ajustar

- Telefone está como `(00) 00000-0000` no `index.html`.
