CSS

CSS (Cascading Style Sheets) é uma linguagem usada para descrever a apresentação de um documento escrito em HTML ou XML. Com o CSS, você pode controlar a aparência de elementos na sua página web, como cores, fontes, espaçamento, layout e muito mais.

Diminua a janela do navegador até menos de 600px de largura para ver o media query trocar o fundo da página e o tamanho das fontes.
